How to Use Ripple Import

Quick start

Step 1 — Add Ripple Import to your board

  1. Open the board you want to import into.
  2. Click + next to your views (Main table, Kanban, …), then Apps → Ripple Import.

Ripple Import opens as a tab on the board. You only do this once per board.

Step 2 — Upload your file

Drag a CSV, XLSX or XLS file onto the upload area, or click it to browse. For an Excel workbook with several sheets, you'll pick the sheet.

No file yet? Under Need a template?, download a CSV template or Excel template with your board's columns already in place.

Step 3 — Check the mapping

Ripple Import matches your file's columns to the board's columns by name and type. Look down the list and adjust anything that's off:

  • Pick a different board column from the dropdown.
  • Choose -- Skip -- for columns you don't want to import.
  • Choose + Create new column to add a column the board doesn't have yet.

Map one column to Item Name (it's usually done for you). Then pick the group the new items go into. Preview Data shows exactly what will be imported, and any row with a problem (an invalid date or email, say) is flagged before anything happens.

Step 4 — Import

Click Start Import. A progress bar shows each item as it's added. At the end you get a summary: items created, subitems, items updated, and anything skipped or failed. Click Show Issue Details for the reason on each row, or Download issues CSV to fix those rows and import just them.

Importing into a brand-new board? On the mapping step choose To new board from file. Ripple Import creates the board with a column for every column in your file.

Update existing items from a spreadsheet

Use this when the items are already on the board and you want to refresh some of their values, for example totals worked out in Excel, prices or statuses. Nothing is duplicated.

  1. Get your data into a file. The easiest way is Export on the upload step (CSV or Excel). It includes an Item ID column, which makes matching foolproof. Any file works as long as it has a column that identifies each item, such as a Case ID, order number or email.
  2. Edit the file and upload it.
  3. Map the column that identifies each row, plus the columns you want to change. Set every other column to -- Skip --, so only the columns you mean to update are written.
  4. Under duplicates, choose Update existing.
  5. In Match rows by, pick your identifying column (Item ID is picked for you when the file has one).
  6. Tick Only update existing items if the file should never add new items.
  7. Click Start Import.

What stays untouched:

  • Columns you set to Skip keep their values on every item.
  • Blank cells in your file never clear a value on the board.
  • Item names change only if you map a column to Item Name.

With Only update existing items ticked, a row whose key isn't on the board, is empty, or appears twice in the file is skipped and listed in the summary with the reason. Without it, rows with no match are added as new items, so one import can refresh existing items and add new ones.

Formula and mirror columns can't be written by any app, so keep calculated results in ordinary columns (Numbers or Text, for example). Other read-only columns, such as Auto number, Creation log, Last updated, Files and Time tracking, are skipped automatically.

Repeat an import with the same settings

Ripple Import remembers how you set up the last import on each board: which columns were written or skipped, the duplicate mode, the match column, and the number and date formats. Next time you upload a file with the same columns, you'll see Same columns as your last import on this board. Click Use the same settings and everything is set up again in one go. Check it, then import.

The settings are kept per board and shared by everyone on your monday account, so a colleague doing the same weekly import gets them too.

Import items with subitems

Ripple Import can build parent items and their subitems from one file. On the mapping step, under How do you want to structure parents & subitems?, pick how your file shows the structure:

OptionYour file looks like
Type columnA column says what each row is: "Item" / "Subitem", or a level number (0, 1, 2…).
IndentationSubitem names are indented with spaces or tabs under their parent.
Parent ReferenceA column on each subitem row names its parent item.
Flat (no subitems)One row per item. This is the default.

To add subitems under an item that's already on the board, choose Add subitems to existing item and pick the parent.

Multi-level boards (up to 5 levels) are detected automatically. The same options build deeper hierarchies, and you can add children under an existing item at any level.

Schedule a recurring import from a link

Point Ripple Import at a file that's updated regularly, such as a daily export from your finance system, and it imports it on a schedule. Runs happen on our servers, so nobody has to have monday open.

  1. On the upload step choose From a link.
  2. Connect your monday account (once). This lets runs happen while you're away.
  3. Paste a link to a CSV or Excel file. Share links from SharePoint, OneDrive, Google Drive, Google Sheets and Dropbox work, and so does any direct HTTPS link. If the file needs a key, tick This link needs an authentication header.
  4. Map the columns. You're mapping the real file, so what you see is what each run imports.
  5. Choose Update existing and a match column, such as an invoice or reference number. This is what stops every run from adding the same rows again.
  6. Click Set up a schedule and choose when it runs: daily, weekdays only, weekly, or every few hours.

The upload step then shows the board's schedules and when the next run is. Open a schedule to pause it, edit it, run it now, or see its last 60 runs with what was created, updated, skipped or failed. If the file changes shape (a column renamed, say), the run stops and tells you why instead of importing the wrong thing.

The file must be reachable over HTTPS. A path on an internal network drive won't work, because runs happen on our servers. Save or sync the file to SharePoint or OneDrive and use its share link. Scheduled runs count toward your plan's monthly imports, like imports you run yourself.

Just want to import a file from a link once? Choose Import once now instead of setting up a schedule.

What happens to rows that are already on the board

When your file contains items the board already has, you choose what happens:

OptionWhat it does
Create anywayAdds every row as a new item, even if one with the same name exists.
Skip duplicatesLeaves items with the same name alone. Only new names are added.
Update existingMatches rows to items (by Item ID, name, or any column you pick) and refreshes their values. Unmatched rows are added, or skipped if Only update existing items is ticked.

Numbers and dates

Real number and date cells in an Excel file are read exactly, whatever your regional settings. The How do you want to parse dates and numbers? options matter when numbers and dates are typed as text, as in CSV files:

  • Date format: MM/DD/YYYY (US) or DD/MM/YYYY (EU/UK). ISO dates like 2026-03-04 always work.
  • Number format: 1,234.56 (US/UK) or 1.234,56 (EU). Currency symbols are ignored.

Header tags (optional)

When Ripple Import creates new columns, it guesses each column's type from the data. To choose the type yourself, put a tag in front of the header in your file:

  • [status] Priority creates a Status column
  • [date] Due Date creates a Date column
  • [numbers] Budget creates a Numbers column
  • [email] Contact creates an Email column

Board column limit

A monday board can have up to 500 columns. Ripple Import checks your mapping against that limit before the import starts. If it would go over, it tells you by how much, keeps Start Import disabled until you skip or combine columns, and suggests importing into a new board instead when that would fit.

FAQ

Will an import overwrite columns I didn't mean to change?

Only mapped columns are written. Set the columns you want left alone to -- Skip --, and use Use the same settings on later imports so those choices are kept. Blank cells never clear values.

Can I try it safely first?

Yes. Duplicate the board in monday (board menu → Duplicate board), add Ripple Import to the copy, and run your import there first.

Why were some rows skipped?

Open Show Issue Details on the summary screen. Every skipped or failed row is listed with its reason, and Download issues CSV gives you just those rows to fix and import again.

Does my file leave monday.com?

Uploaded files are read in your browser and go straight to your board. They never reach our servers. Scheduled imports from a link are the exception: the file is downloaded on monday.com's own app platform, imported, and discarded. The privacy policy has the details.

How many imports can I run?

The Free plan includes 10 imports a month, and paid plans include more. The current count is shown at the bottom of the Ripple Import view.
