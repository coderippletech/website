What happens between dropping the file and seeing the board.

Scheduled imports

Point it at a link instead of a file. It fetches and updates your board every day, on the weekdays you pick, or every few hours. Nobody needs monday open.

CSV & Excel

Drop in a CSV, an XLSX, or a workbook with several sheets. The file is parsed in your browser, instantly.

Smart column mapping

Columns match your board by name and type before you touch anything. Adjust, skip, or create new columns as you go.

Items & subitems

Import parent items with subitems. Hierarchy is auto-detected from type columns, indentation, or references.

Multi-level boards

Full support for multi-level boards with up to 5 levels of nesting. Add children to any item at any depth.

Update existing items

Match rows by Item ID, name, or any column, like a case or order number. Only mapped columns change, blank cells never wipe values, and update-only mode never adds items.

Same settings, one click

Ripple Import remembers each board's last import. When the same file comes back, one click restores the columns, match column and formats.

Templates & live exports

Grab a blank template that matches your board, or export the current items with their values. Edit offline, re-upload to refresh.
