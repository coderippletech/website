RippleBug for Jira — private beta

Thanks for trying it. Setup takes about five minutes.

RippleBug turns a failed test, or any bug a tester sees, into a Jira bug with the screenshot, screen recording, and console and network logs (secrets redacted) in one click. The bug can be linked to the test run and step it came from in Xray, Zephyr or AIO Tests, or to a story. The RippleBug for Jira app shows all of that inside the issue.

What you need

  • A Jira Cloud site, and a site admin for step 1.
  • Chrome or Edge for everyone who files bugs.

1. Install the Jira app (site admin, once)

Open the install link, pick your site and approve. The app reads issues and attachments as the person viewing them; it copies nothing out of Jira.

2. Install the extension (everyone)

Add RippleBug from the Chrome Web Store and pin it. Ctrl+Shift+Y opens the side panel.

3. Sign in to Jira

In the side panel: Settings → Jira Cloud → Sign in with Atlassian, then choose your site. Everyone files as themselves; nothing to copy or paste.

4. File a bug

  • Open the page with the bug and the side panel takes a screenshot. Add a recording, crop, or annotate if it helps.
  • Pick the Jira project, write a title and what happened, and press File Bug.
  • Found by: pick the test run and failing step, and the bug is linked to it and recorded as a defect on that run. Using Xray, Zephyr or AIO Tests? Add your API key once under Settings → Test management. No test tool? Link the bug to a story instead.

5. See it in Jira

Open the bug in Jira. RippleBug evidence in the right sidebar shows the counts; Open evidence shows the screenshots, the recording, steps, environment, and the console and network logs, with Copy for AI for Claude Code, Cursor or any assistant.

Optional: connect a RippleBug board

A RippleBug board is a triage board with MCP for AI agents and AI triage. Connect one under Jira settings → Apps → RippleBug and each issue shows its card's status. The board is separate, with a free plan; everything above works without it.

What we ask

  • Use it for your real bugs for two to four weeks. It's free during the beta.
  • Tell us what's missing or annoying, any time.
  • A 15-minute call at the end.

Privacy

Bugs and evidence go only to your Jira site. Our server is used to sign you in to Jira (it keeps no tokens), and the Jira app sends us weekly counts of bugs filed, never their content. Details: Ripplebug privacy.
